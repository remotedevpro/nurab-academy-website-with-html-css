
# 🎓 Nurab Academy Website

A modern, fully responsive educational landing page built with **pure HTML5 and CSS3**. This project showcases clean UI design, flexbox/grid layout techniques, and responsive design patterns without relying on external frameworks or JavaScript.

---

Check out the live website here:

---

## ✨ Features

- 📱 **100% Responsive Design:** Smooth layouts across desktop, tablet, and mobile devices using media queries.
- 🎨 **Pure HTML & CSS:** Built entirely from scratch with zero framework dependencies (no Bootstrap, Tailwind, or JS libraries).
- 🧩 **Semantic HTML5 Structure:** Accessible and SEO-friendly structure using tags like `<header>`, `<nav>`, `<section>`, and `<footer>`.
- ⚡ **Modern CSS Layouts:** Utilizes **CSS Flexbox** and **CSS Grid** for precise element alignment.
- 🎯 **Clean UI/UX:** Styled navigation bar, hero banner, course cards, features section, and a clean contact area.

---

## 🛠️ Built With

* **HTML5** - Page structure & content markup
* **CSS3** - Custom styling, Flexbox, Grid, animations, and media queries
